## Overview

Slackbot gives agents workspace-wide read access to a Slack workspace on behalf of the installing user - search messages and files, browse channel and thread history, and look up users and channels - while continuing to post and react as the bot. Includes direct messages and user email addresses so agents can search across DMs and resolve users by email.

### SLACKBOT_CREATE_LIST

**MCP Tool**: `mcp__composio__SLACKBOT_CREATE_LIST`

Creates a new Slack List via `slackLists.create`. Provide a `name` and, optionally, a `description_blocks` description and a `schema` of typed columns. You can instead copy an existing List's structure with `copy_from_list_id` (and its rows via `include_copied_list_records`), or enable task-tracking columns with `todo_mode`. Returns the new List's `list_id`. Requires a user token with the `lists:write` scope.

**Parameters:**
  - `name` (string, required): The name (title) of the Slack List to create, e.g. 'Sprint Tasks'. This is shown as the List's title in Slack and is required.
  - `schema` (array, optional): Column definitions for the List. Each entry is a column object describing a typed column (its `name`, `type`, and any type-specific options such as `select` choices). Supported column types include `text`, `select`, `user`, `date`, `number`, `checkbox`, and others. Omit to create a List with Slack's default columns.
  - `todo_mode` (boolean, optional): Set to true to create the List in to-do mode, which adds Slack's built-in task-tracking columns (such as assignee, due date, and completion status) so the List behaves as a task tracker.
  - `copy_from_list_id` (string, optional): ID of an existing Slack List to copy the structure from, e.g. 'F0123456789'. When provided, the new List is created with the same columns as that List. Use `include_copied_list_records` to also copy its rows.
  - `description_blocks` (string, optional): Rich text describing the List, shown beneath the title. Slack stores this as Block Kit `rich_text` blocks. For convenience you may pass a plain string (it is wrapped into a `rich_text` block automatically), a single block dict (wrapped in a list), or an already-formed list of blocks (passed through unchanged). Omit to create a List with no description.
  - `include_copied_list_records` (boolean, optional): When copying from another List via `copy_from_list_id`, set to true to also copy that List's existing items (rows) into the new List. Has no effect unless `copy_from_list_id` is set.

  - `parent_item_id` (string, optional): ID of an existing item (row) to attach the new row to as a subtask. When provided, the new row is created as a sub-item of that parent.
